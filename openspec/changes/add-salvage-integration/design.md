# Salvage and integration
The repaired manipulator recovers one stock cradle at the tower socket (4 alloy, 4 conductor, 2 sealant; cost 150 kJ, 100 heat). Initial common stock also permits repair without coupler access. The controlled bench spends 100 kJ/120 heat to understand the coupler. Adapter cost is 3 alloy/3 conductor/1 sealant and 300 kJ/400 heat, requiring fabrication priority. One removable socket costs 50 kJ/50 heat to install; it rejects peak pulses and yields 220 kJ/s, 12 heat/s instead. Transaction guards precede all deductions and duplicate requests cannot grant items.

Installation extends the real support world westward, X -260..-80, Z -180..-30. Collision and a visible turquoise bridge use the same dimensions. Uninstalled traversal there is unsupported. Only the primary tower socket may retract the bridge; the player cannot remove support while parked over it. Save restore selects the same extended world before geometry validation. Bulk/test/adapter/installation identity is persisted explicitly. M1d supplies the coupler; unit fixtures inject it only to isolate integration behavior.
